# 144. Binary Tree Preorder Traversal

## Problem

Return the preorder traversal of a binary tree.

## Approach

A recursive depth-first search appends the current node first, then visits the left and right subtrees.

## Complexity

- Time: `O(n)`
- Space: `O(h) auxiliary recursion space and O(n) for the result`
